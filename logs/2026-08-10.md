# 2026-08-10

## Alcohol over time — timeline chart merged into the alcohol-free streak widget

**Files changed:**
- `betalog-react/src/lib/stats.js`
- `betalog-react/src/lib/__tests__/stats.test.js`
- `betalog-react/src/components/dashboard/AlcoholFreeCard.jsx`
- `betalog-react/src/components/profile/ProfileTab.jsx`

### Changes

**`stats.js` — new `buildAlcoholTimeline(drinkLog, mode)`**
- Buckets the drink log into 30 days / 12 weeks / 12 months, always ending with the current day/week/month. Weekly buckets are Monday-aligned (reuses `mondayOf`), monthly buckets are keyed `YYYY-MM`.
- Returns per-bucket `units`/`kcal`/`entries` plus window totals: `totalUnits`, `totalKcal`, `dryDays`, `drinkingDays`, `avgUnitsPerWeek`, `maxUnits`, and `prevUnits` (same-length window immediately before) with `hasPrevData` so the comparison is only shown when there's history behind it.
- `guideline` exposes the UK low-risk 14 units/week (scaled for monthly buckets, null for daily — there isn't a daily guideline).
- Added date helpers `shiftDate`, `shiftMonth`, `daysBetween` alongside the existing `mondayOf`/`todayStr`.

**`AlcoholFreeCard.jsx` — one widget, two stacked sections**
- Top: the alcohol timeline — total units for the window, 30d/12w/12m toggle, bar chart, dashed 14-unit guideline, and a footer with dry days, kcal, and average units/week. Bars are amber, turning rose when a bucket exceeds the guideline; dry buckets render as a faint baseline stub so the timeline still reads. A "vs prev" delta chip sits top-right (down = green).
- Bottom: the existing alcohol-free streak block, unchanged in behaviour (tiers, grind phases, 7-day strip, growth fact).
- Both share one card shell, so the tier colour still themes the whole widget. Timeline colours are deliberately fixed so the chart reads the same at every streak length.
- The timeline section is skipped entirely when nothing has ever been logged; when the window itself is fully dry the chart collapses to a compact strip instead of showing empty air.
- Removed the old "this week: ~N kcal from drinks" line — the timeline footer now covers kcal.

**`ProfileTab.jsx`** — widget label updated to "Alcohol over time & streak". Widget key stays `alcoholFree`, so existing dashboard order and visibility preferences carry over untouched.

### Testing (alcohol widget)
- 10 new unit tests for `buildAlcoholTimeline` (bucket boundaries for all three modes, unit/kcal aggregation, dry-day counting, previous-window totals, guideline, empty log, unknown mode). All pass.
- 4 pre-existing MET-related test failures in `stats.test.js` are unchanged by this work.
- `npm run build` clean. Widget rendered and screenshotted in all three timeframes against seeded data.

## Docs: branching model corrected — feature branch → preprod → main

**Files changed:** `CLAUDE.md`, `docs/guides/betalog_sdlc.md`

Both docs still described a long-lived `betalog-react` development branch as the place all work happens. That branch is gone from the remote. Replaced it with an explicit three-stage flow — **feature branch → `preprod` → `main`** — and created `preprod` on the remote so the documented flow is real.

- **`preprod` branch created** from `main`. It's the pre-production/staging branch: finished work is merged here and checked on its Cloudflare preview deploy before release. It replaces the retired `betalog-react` branch.
- `CLAUDE.md` — Branches section rewritten around the three stages. `main` is production, a merge into it is a live release, nothing is committed there directly and nothing reaches it except a merge from `preprod`. Feature branches now branch off `preprod`. `npm run build` and `npm test` must pass before promotion.
- `docs/guides/betalog_sdlc.md` — branch table, start-of-session commands, and the merge steps split into "merge to pre-production" → "verify the pre-prod preview" → "promote to production". Pre-merge checklist now gates on the preprod preview and `npm test`; rollback notes that hotfixes take the same route; flow diagram redrawn with the preprod column.
- Also corrected `CLAUDE.md`'s "no tests, no linting" line — there is a Vitest suite (`npm test`) and ESLint (`npm run lint`); still no CI, so both run locally. Added `npm test` to the Development commands.
