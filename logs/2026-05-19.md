# 2026-05-19 — Work Log

## Hangboard timer audio fixes

### Problem 1: sounds out of sync after backgrounding / pause
**Root cause:** Timer used `setInterval` tick-counting (one decrement per fire). Mobile browsers throttle intervals when backgrounded, causing the countdown to fall behind real time and sounds to fire late.

**Fix — wall-clock anchoring** (`HangboardTimer.jsx`):
- Added `phaseStartRef` — stores `{ at: Date.now(), timeLeft: n }` whenever a phase starts or resumes
- Interval now runs at 200ms and computes `remaining = timeLeft - Math.floor(elapsed / 1000)` from the wall clock, not tick counts
- If the app was backgrounded, the first interval fire after returning snaps the countdown to the correct remaining seconds
- Phase transition: sets `phaseStartRef = null` before calling `setTs(nextTimerState)` to prevent a 200ms re-entry race
- Same null-guard added to `skipPhase`, `togglePause` (on pause), and `endAndSave`

### Problem 2: sounds too quiet
Bumped all `playTone` gain values:
- `countdownTick`: 0.25 → 0.55
- `hangStart` / `readyStart`: 0.4 → 0.7
- `restStart`: 0.3 → 0.6
- `setRestStart`: 0.3 → 0.6
- `lastSeconds`: 0.2 → 0.55 (was the quietest)
- `done` chord: 0.3–0.35 → 0.6–0.7

### Bonus fix: `readyStart` was defined but never called
Added `sounds.readyStart()` to the phase-transition sound effect for `ts.phase === 'ready'`. Timer now beeps on "Get Ready" as well as on hang/rest transitions.

### Problem 3: beeps too harsh/thin
Rewrote `playTone` with a richer synthesis chain:
- **Two oscillators**: triangle wave (fundamental) + sine wave (octave above, at 25% level) — triangle has natural odd harmonics that sound warm/mellow vs a pure sine
- **Low-pass filter** (BiquadFilterNode) rolls off harsh upper frequencies
- **8ms linear attack** ramp on the master gain removes the click/pop from instant-on onset
- **Durations extended**: countdownTick/lastSeconds 70–80ms → 120ms so the timbre has time to register; done chord notes extended similarly

Overall character shifts from "electronic beep" towards soft chime/marimba.
