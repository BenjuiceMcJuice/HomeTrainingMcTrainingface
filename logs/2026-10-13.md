## A single exercise looked struck through in History's edit (BTL-B155)

Ben, with a screenshot of *Scapula Pulls* opened from History: *"the scapula pull name looks like
it's got a strike through when viewing form history."*

**Cause.** `ExerciseCard` in `GymLogSheet.jsx` drew the done style (line-through, 60% opacity, green
border) from `card.done` whether or not the card had a tick. Only a routine's cards are ticked;
a single exercise is always saved `done: true`, and edit mode seeds `done: se.done !== false` — so
every single-exercise session opened from History looked crossed out.

**Fix.** The style follows the tick only where there is one: `done = showDone && !!card.done`.
Reproduced in Chromium against the harness (line-through / opacity 0.6), then gone with the fix
(none / 1). Merged to `main` as a fix of a broken screen; cache v91.

## A gym session stays open until Done (BTL-B154)

Ben: *"In training mode when we click log can we maybe have the same as the climbing whereby until
you finally save it it shows as an active session perhaps? Does this make sense?"*

It did: the climb logger has saved as you go since BTL-B76 and only ends a session on Done or
Finish (B109). The gym sheet was the opposite — nothing written until *Save*, and closing it asked
*Discard this session?* (B148). Built the climb model into the gym sheet, on
`claude/gym-open-session`; spec `docs/specs/betalog_logging_as_you_go_spec.md` §7.

**What it does.**
- Log › Train's sheet writes the session on the first change (tick, set, reps, weight, feel,
  notes, date) and on every change after, with `endedAt: null` and the feel null until picked.
  Opening a routine and closing it untouched writes nothing.
- Closing the sheet loses nothing and asks nothing. **Done** needs a feel and stamps `endedAt`.
  **Delete session** (asks first) throws an open one away.
- The open session is offered as a card on Train — *Today · Push Day*, *2 of 3 done*, Continue
  session / Finish — a row on the Dashboard (*Continue · Push Day · 2 of 3 done*, one per open
  kind, so a climb and a gym session can both show), and **OPEN** + *Continue logging* in History.
- A routine's ticks are written as they stand while open; on Done or Finish, nothing ticked means
  all done — the sheet's old rule, now applied at the end (`gymExercises`, `finishPatch`).
- History's gym edit sheet is unchanged: change-then-commit, asks before discarding.

**Decisions.** Write on the first *change*, not on open — opening a routine to look at it should
not put a session in the log. Ticks stay raw while open so a continued session shows what was
really ticked. The sheet is given a snapshot of the session when it opens, not the live copy,
because it re-seeds whenever `initialSession` changes.

**Found while checking.** The X still asked *Discard this session?* after a tap — the discard
guard marks the sheet dirty on any click. Live mode now closes straight away.
