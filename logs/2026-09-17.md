## Hangboard timer keeps the screen awake

**Branch `claude/iphone-screen-lock-pwa-4cvum5`, not merged.**

- **`src/hooks/useWakeLock.js`** — one hook, `useWakeLock(active)`. Requests
  `navigator.wakeLock.request('screen')` while `active` is true, releases it on false or unmount.
  iOS drops the lock every time the app leaves the foreground, so it listens for
  `visibilitychange` and asks again on return. Missing API (iOS before 16.4, Firefox) and a
  refusal (Low Power Mode) are both silent — the timer works as before, the screen just follows
  auto-lock.
- **`HangboardTimer.jsx`** — holds the lock whenever the sheet is open and the phase is not
  `preview` or `done`. Paused counts as running: the climber is still on the board.
- Nothing else is timed. The only other `setInterval` is the Coach page's rate-limit countdown.
- Cache v29 → v30.

**651 tests, 0 lint errors, build clean.** Not verified on a phone — the timer is behind
sign-in and the lock only means anything on a real screen. Check on the preview deploy: start a
routine, put the phone down for longer than Auto-Lock, and the display should still be on.
