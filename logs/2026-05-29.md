## Gym stats + Cardio stats dashboard widgets — implemented

Two new toggleable dashboard widgets showing 90-day training summaries.

**CardioStatsCard** (`cardioStats` key):
- Filters sessions to `type === 'cardio'` in last 90 days
- Shows total session count + total duration (right-aligned teal badge)
- Detail line: breakdown per activity type with distance where available
  e.g. "Swim 5 · 3.5 km  ·  Run 2 · 12.4 km  ·  Walk 1"
- Distance computed from km/miles/m/lengths (pool length aware); laps excluded
- Returns null if no cardio sessions in window

**GymStatsCard** (`gymStats` key):
- Filters sessions to `type === 'gym'` in last 90 days
- Shows session count + total sets logged (skipped exercises excluded)
- Dominant muscle group derived from most-frequent exercise category
  e.g. "186 sets  ·  Back heavy"
- Returns null if no gym sessions in window

Both default to OFF for existing users (opt-in only, so current users aren't pushed over MAX_WIDGETS=5 without choosing to enable them). New users get them off by default too — toggle in Plan → Profile.

Files changed:

- `src/components/profile/ProfileTab.jsx` — `gymStats` + `cardioStats` in `WIDGET_OPTS`; `OPT_IN_KEYS` guard defaults them off

Build clean.

## Sport cardio tile — implemented

Replaced the Yoga standalone tile with a **Sport** tile covering 32 activities with baked-in MET values. Yoga and Rowing both fold into the Sport list.

**Calorie calc:** `baseMET × weight × (duration/60) × effort_modifier`. Effort modifiers: Easy 0.8–1.0, Moderate 0.9–1.15, Hard 1.1–1.35, Very Hard 1.3–1.55, Max 1.5–1.75. Same `estimateCalories` path as swim/run/cycle.

**UX:** Sport picker opens full-screen (not a bottom sheet) — search pinned at top, scrollable list of sports with MET values below. Full-screen ensures the keyboard never obscures the search input regardless of result count. Selecting a sport collapses back to the normal bottom-sheet form with a "Change" badge.

**Data:** `cardioSportKey` stored on session (the sport name); `cardioLabel` set to the sport name so existing SessionCard/SessionDetailSheet display logic works unchanged.

Files changed:
- `src/lib/stats.js` — `SPORT_MET_VALUES` (32 sports), `SPORT_EFFORT_MODS`, `getMETRange` updated to handle `activity === 'sport'` with optional `sportKey` param; exported `SPORT_MET_VALUES`
- `src/components/log/CardioLogSheet.jsx` — Sport tile replaces Yoga; full-screen picker panel when no sport selected; sport badge + Change button when selected; `cardioSportKey` saved; `getMETRange` call passes `sportKey`
- `src/pages/Log.jsx` — tile strip updated (Yoga → Sport)
- `src/components/log/SessionDetailSheet.jsx` — both `getMETRange` calls pass `cardioSportKey`
- `src/pages/Dashboard.jsx` — `ACTIVITY_LABEL` updated; both MET fallback calls pass `cardioSportKey`

Deployed to main → betalog.co.uk. Build clean.
