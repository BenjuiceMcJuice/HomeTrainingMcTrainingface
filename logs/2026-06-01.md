## Grade goal display — 90d current form + send count

Replaced the binary 0%/100% progress bar on grade goals with a more honest indicator.

- **Current grade** uses 90d consistent (falls back to all-time in grey with "(all time)" label if no recent sessions)
- **Send count** — counts sends at the target grade in the last 90 days, so momentum shows even before "consistent" threshold is hit
- **Days remaining** — colour-coded grey → amber (<30d) → red (<7d)
- No percentage bar — a one-grade increment goal can only ever be 0% or 100%, so it was meaningless

Display: `6c → 7a · 2 sends (90d) · 88d` or `V4 (all time) → V5 · 0 sends (90d) · 88d` when returning from injury

`goalProgressForGrades` helper removed from `LevelCard.jsx`. Dashboard computes `boulderGoalSends` / `ropeGoalSends` via `useMemo` over `recent90` sessions, filtered by climb-level discipline.

Files changed: `LevelCard.jsx`, `Dashboard.jsx`
