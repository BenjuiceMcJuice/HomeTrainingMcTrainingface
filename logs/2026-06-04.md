# 2026-06-04

## Routine weight input — fix inability to retype value

Fixed a bug where the weight field in the routine exercise editor would snap back to 0 whenever the field was temporarily empty (e.g. on backspace), making it impossible to clear and enter a new value.

Root cause: controlled input with `value={item.targetWeight ?? 0}` and `onChange: Number(e.target.value) || 0`. The `|| 0` fallback meant any empty/invalid intermediate state immediately committed 0 to state, re-rendering the field with "0" before the user could finish typing. Negative values were also broken — typing "-" produces `""` in a `type="number"` input, which `|| 0` converted to 0.

Fix: switched to an uncontrolled input (`defaultValue`) that only commits to parent state when `parseFloat` produces a valid number. An `onBlur` handler resets the displayed value to the last known good value if the user leaves the field empty. The `key` prop (`item._uid + '-weight'`) ensures the input remounts if the exercise changes.

Files changed: `src/components/routines/RoutineModal.jsx`
