# 2026-05-22

## Cardio session type

Added `"cardio"` as a first-class session type for cross-training logging (swim, run, cycle, row, walk, yoga, other).

**Files changed:**
- `src/lib/types.js` — `"cardio"` added to `SessionType`; 6 new cardio fields documented on `Session`
- `src/hooks/useSessions.js` — cardio field defaults in `addSession`
- `src/components/log/CardioLogSheet.jsx` — new slide-up log form
- `src/pages/Log.jsx` — fourth mode tab "Cardio" (teal)
- `src/components/log/SessionCard.jsx` — teal badge, `cardioDetail()` summary, `sessionName()` update
- `src/components/log/SessionDetailSheet.jsx` — `CardioDetail` component

**Key decisions:**
- Pool length options: 25m / 33m / 50m / Other (33m added for user's local pool)
- Derived distance shown live in form and in session detail (e.g. 20 lengths × 33m = 660m)
- No edit flow in v1 — delete and re-log is sufficient
- Streak/count stats required zero changes — all calcs already iterate all session types
