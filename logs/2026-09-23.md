## Pyramid count column is always sends out of eight (BTL-B56)

**What changed.** `PyramidChart`'s count column used *have/need* for Send goals and sends out of
`OWN_SENDS` only for Own goals (the `ownCounts` prop, BTL-B52). The prop is gone: every pyramid
now shows each grade's sends out of eight — *owned*, 6/8, 0/8 — on the Dashboard, Plan › Goals,
the New Goal sheet and a friend's pyramid. The blocks are unchanged, still the 1·2·4·8 pyramid for
the target, so the blocks answer *is the pyramid built* and the count answers *how far is each
grade from owned*. On a Send goal *4/4* only repeated what the blocks already showed.

- The count goes green only when the row is owned; a pyramid row that is full but not owned stays
  grey, as it already did for Own goals.
- Tiers from an older build with no `own` still fall back to *have/need*, with green when met.
- `Math.min(own, 8)` dropped: at 8 or more the row reads *owned* anyway.

**Files.** `components/ui/PyramidChart.jsx` (prop removed, doc rewritten),
`components/dashboard/LevelCard.jsx`, `components/goals/GoalsSection.jsx` (two call sites).
Spec §9 paragraph on the count column updated; BTL-B51's check wording updated; BTL-B56 opened as
