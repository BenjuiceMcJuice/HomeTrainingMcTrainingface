# 2026-05-27

## Gym log: add/remove sets during logging

**`src/components/log/GymLogSheet.jsx`**
- Added `addSet(cardIdx)` and `removeSet(cardIdx)` functions — `addSet` copies the last set's reps/weight as the default for the new row; `removeSet` drops the last row (minimum 1 set enforced).
- `ExerciseCard` now accepts `onAddSet` / `onRemoveSet` props and renders `+ Set` / `− Set` buttons below the set rows. `− Set` is hidden when only 1 set remains.
- Works in both add mode (from routine or single exercise) and edit mode (editing an existing session).
